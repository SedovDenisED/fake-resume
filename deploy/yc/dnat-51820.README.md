# Резервный вход: UDP 51820 DNAT → дом awg1

Текущая схема не ломаем:

```text
телефон (AmneziaWG) → YC:51820/udp → DNAT/MASQUERADE → дом_ISP:51820 → awg1
```

На YC по-прежнему:

- `home_ip.txt` — актуальный внешний IP дома
- `rules_backup.sh` / `iptables-rules.service` — восстановление после ребута preemptible VM
- обновление DNAT через `yc` / SSH с дома при смене домашнего IP

Новый вход Happ (443) и этот резерв **сосуществуют**. Порт `51821` — только служебный AWG YC↔дом, не путать с `51820`.
